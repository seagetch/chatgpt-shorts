# 初読批評：型のない一個

企画メモを見ずに本文を通読。量は短編として適切。停止したプレスの代わりに、同じ音を出す二つの金具の差を見せる。さらに終盤、ひもの片側だけを引くと赤い見本さえ落ちないところまで実演するので、引き継がれるのが「勘」ではなく検査方法の検査だと、台詞だけに依存せず伝わる。終幕の矢印は冒頭の見学導線を回収する。閉業と転職、電話を取り次ぐだけだった過去、次の職場で答える現在も連動する。

| 観点 | 初稿判定 | 所見 |
|---|---|---|
| 因果・時系列 | PASS | 搬出前日・公開当日、危険判明、代替実演、引き継ぎが一続き。 |
| 位置・物の連続性 | 要修正 | 先に箱をどけたのに「良品の列へ戻しかけた」のは動線が分かりにくい。空いた台へ指が迷う程度に。黄色の搬出線が撮影禁止境界にも使われるなら、滝沢が立入境界として臨時に使ったと分かる表現に。 |
| 技術・安全 | PASS（物語上） | 停止札、障壁、手渡しなし。音、片爪、引く向きがつながる。振動試験と混同しない応答も有効。定量的検査規格の正しさは未検証。 |
| 人物・圧力 | 要補強 | 転職先の人がいきなり見物に来るのは都合がよい。交流会で工場を回る、と面接時に耳にした程度の軽い先触れを。彼の所属・職務を説明しすぎる必要はない。 |
| 決着・余韻 | PASS | 「何を書くか」より赤い見本の動きで伝え、終幕で今後の能動性も示した。 |

任意の研磨：「この場で振動の試験」と「走ってる」の間に、質問者が機械の稼働を指すことが分かる一語を。『もとの金型を削った傷でも』の一文は、初読では誰もその説を出しておらず不要に謎を匂わせるため、削るか斜線で古い無印状態が終わる描写に置き換える。

局所修正の再読後に受入可。中心構造の組み直しは不要。
