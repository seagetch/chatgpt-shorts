# 『二度目の避難』独立初読レビュー

2026-11-14 UTC。完成稿doc.mdのみを先に読み、idea.mdには依存しない。対象は犯人当てではなく、所在・時間順を解くミステリ＋救出サスペンス。以下は初稿への評価であり、修正後の合否と混同しない。

## Findings（重大度順）

1. **high / ミステリ機構の行動上の必要性**
   - 二人は地階で既に手前・隣の二室を開けている。残る奥の扉の袋を見つけなくても、その扉を開ける順番だった。袋と点呼時刻の解釈は、捜索の優先順位や方法を変えておらず、探索中に被害者を発見するサスペンスへ寄っている。
   - また本文は要と兄の帰還を明示するので、「点呼が正しかったはずなのに」という謎は読者にとって初めから解消可能。これを高度な不可能状況として扱わないこと。
   - 最小修正：管理人の全室確認を受けて地階から別方面へ行きかける時点で、袋がその確認の意味を問い直させる。その後に呼名のみだったと分かり、未検証の奥を先に開ける。推理が救助行動を実際に変える形にする。
2. **high / 被害者の通信手段**
   - 呼出しが続く携帯を本人が所持している印象なのに、目を開け会話できる要が応答も救援依頼もしなかった理由がない。移動困難は手元の電話操作まで自動的に妨げない。
   - 最小修正：携帯は受付に置いた上着のポケット等、本人の手の届かない場所にあることを事件前に提示。もしくは救助時に手の届かない鞄の中で鳴っていたと観測する。後者も居場所の決定証拠にはせず、行動上の欠落を埋めるだけにする。
3. **medium / 防音扉と布の位置**
   - ドラム音がほぼ消える重い防音扉の下に、床との隙間を使って布の持ち手が挟まる描写は、気密性との関係を直感しにくい。絶対不可能と断定はしないが、主要手掛かりの幾何として不安定。
   - 薄い持ち手が戸当たりの縦縁に挟まる、とし、開いた時の袋位置も合わせると自然。布が厚すぎて施錠不能にならないよう、厚さや閉鎖音響の専門断定は避ける。
4. **low / 兄の非合理性と作品形式の区別**
   - 兄は最終同行者で、車を移動させたことも知り、弟帰宅の嘘を重ねるため早くから露骨に怪しい。whodunitとしては容疑者場不足だが、支配的な兄の行動を崩す救出サスペンスなら欠点とは限らない。
   - 他の職員を無理に容疑者化せず、謎の分類を正確に記録する。自白は押した・施錠した事後確認であり、袋から犯人有罪を演繹したとはしない。

## Logic chain
真正の点呼 → その後に帰還しても矛盾しない → 車の不在は別運転者により帰宅証明から除外 → 点呼後に渡した袋が地階室内にある → 外からの無応答は防音ゆえ空室証明にならない → 開けて安否を確かめる。

この論理に隠された決定情報はない。ただし初稿では最後の開扉がすでに進んでいるため、論理の行動上の必要性が薄い。
