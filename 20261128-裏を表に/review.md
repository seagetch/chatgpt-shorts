# 初稿批評：裏を表に

初稿の本文から読み取れる筋だけを再構成した。別人による査読ではない。ハルは練習紙の文字に従って二人目を探す。原因は綾が一つの版で二つの区に対応しようとしたこと。まだ店にある二束と、既に持ち出された二十枚は別の対応が必要。杉並の受け取りは二時。店の現金が足りず、二時を過ぎて届けた分はあとから代金が入る。ハルは先回りで配り手を見つけ、渡し済みの家を再訪してもらう。投票日の朝、ハルの練習紙と本物の用紙は別々に扱われる。

| 観点 | 初稿判定 |
| --- | --- |
| 因果・情報開示 | PASS。本人の選択前に定数、限度、最初の二十枚、二時の約束が示される。日当と失敗の責任は和解で消えない。 |
| 時刻・紙の物量 | 要改稿。一時台と明記し、四十枚引渡しと残りの夕方配送を本文で閉じる。印刷の乾きと展開場所は実測していないので印刷機の仕様や加工速度の精密な主張はしない。 |
| 配紙の動線 | 要改稿。ハルが持ち出す端切れと杉並の青い目印が混同される。「白い紙」は練習紙とは別の端紙。九枚／十一枚を同じ二十枚として追跡し、渡し済みの家は配り手本人が回る。 |
| 時代の具体性 | 要改稿。「入場の知らせ」を当時の当該投票所にあったと断定できない。名簿の確認だけにする。現物未調査の選挙用紙の版面・紙質は描かない。 |
| 人物・終幕 | PASS。綾は雇い主に黙って従わず、ハルも仕事と家に戻る都合で動く。最後まで選んだ候補者名は見せない。表裏を名指しする心の説明は抑え、本人が目で紙を追う動作を残す。 |
| 類型 | PASS。歴史職能は『襖の値段』に近いが、読まれた後の誤りと印刷前の誤りを別々に正し、受け手の行動へ橋を渡す。価格交渉そのものを決着にしない。 |
