# 歌の前に二つ

　歌が始まる前に、木を打つような音が二つした。

「ここで一拍、待つんだよ」

　青木智也さんが、レコードの脇で指を立てた。二つ目のあとで椅子を引くと、椅子の音が歌い出しに重なる。遅れて入ってきたお客には、後ろの柱の所で待ってもらうのだそうだ。

「映画のほうでは、この歌の間に女が靴を履くんです。靴が左右違うって、歌が終わるまで誰も教えない」

「それで歌い直しはありませんでしたの？」

「靴のほうの話ですよ」

「存じておりますわ」

　久条麗華お嬢様はそう言って、試しにかけた盤を外すように顔を向けられた。赤い丸のある紙袋へ智也さんが戻し、代わりに私が持参した銀色の印の盤を卓に置いた。同じ歌手の、同じ曲である。久条家では銀のほうをよくかける。台座を掃除していると、二つ打つはずのところで、いきなりピアノが鳴るので分かる。

「本番には、傷の少ないほうを」

　お嬢様は二枚を見比べておっしゃった。赤いほうが安く見えたのだと思う。傷は、むしろ銀の外縁のほうにあった。

　この町で撮られた古い映画を月に一度観る会で、今日は映写の代わりに歌を聴かせる。会場は青木さんのもと家具工房だった。道路に面した一階が受付とかつての作業場、二階が客席で、柱は椅子よりよほど大事そうに残されている。上映会に戻すには二階の床板を直さなければならない。そのための寄付を、会計の春江さんがひとりずつ受け取っていた。

「親父は、聞こえたら金を払ったと思うんです」

　階段へ行きかけた智也さんが、振り返った。

「お父様が何をお聞きに？」

「先週、荷物を出してくれた人の賃金を。僕が二人に今夕と約束しました。さっきまた、来月払うから電話しろと」

「電話すれば来月になるとお考えですのね」

　智也さんは答えず、階段の上から父親の名を呼んだ。父親は会を代表して開会の挨拶をする。まだ誰もいない椅子へ向かって、声の高さを試していた。

　　　　　＊

　曲目の最初にどちらの盤を使うか、司会と決めたのはそのあとである。銀のほうは傷こそあったが、歌に入る溝は無事だった。司会に盤を渡し、私は一階へ降りた。

　四時の少し前、春江さんと、台所脇の小さな控室で寄付を数えた。九万ちょうど。私は札がばらけないよう、紙の帯を巻いた。青鉛筆で九万と書くと、帯の折り目で最後の一画だけ曲がった。そのまま白い小封筒に収めた。

「また立て替えたことにされると困りますから」

　春江さんは、私にも金額の下に名前を書いてほしいと言った。先月、代表が来客に茶菓子を出し、その代金を寄付から引いた。帳面には相談なしで「春江立替」とあった。受け取っていない金の受領を取り消すほうが、受け取る手続きより面倒だったそうだ。

　窓の掛け金を確かめ、二人で部屋を出た。そのとき二階で開会を知らせるベルが鳴った。音の切れたところで春江さんが扉に鍵を回した。

「一つは私。一つは鍵当番の智也さん。もう一つは照明の冴子さん。そっちは余分なんですけど、明るいところでないと鍵を探せないからって、返してもらえなくて」

　ほかに戸はなかった。窓の下は道路である。薄いカーテン越しに、自転車で買物に行く人の頭が通った。

　受付の卓を外のガラス戸の脇まで持っていってほしいと言われ、私は卓の端を持った。遅れて来た人に混じって椅子が足りないと言いに来た方もいて、二人ともそこを離れられなくなった。上で挨拶が済むと、拍手のあとに低い音が鳴った。曲は聞こえていたが、一階では、知っていても歌詞を追えるほどではない。

　ちょうど歌が終わるころ、翌日の預入に使う大きな封筒を、春江さんが受付の引き出しから出した。彼女は私といっしょに控室へ戻った。鍵は先ほどと同じように回った。

　窓は内側で掛かったままだった。机の下を二人で探した。何も落ちていない。白い封筒ごとなかった。

　春江さんは、膝の上に両手を並べたまま言った。

「今度は、誰の名前で書かれるんでしょう」

　私は郵便局の封筒を受け取って、卓に戻した。空のまま糊をつけてしまいそうな手をしていた。階段の下から、お嬢様、と二度呼んだ。

　　　　　＊

　控室の鍵を持つ方だけにお声がけするまで、誰も帰らないように頼んだ。ちょうど二曲目の前の休憩だった。春江さんは机のところに立ち、九万円、と一度だけ金額を言った。

　冴子さんは右手に小さな懐中電灯を持って来た。照明卓の表示が薄く、虫眼鏡代わりに使うのだと教えてくれた。

「また私の交通費の話になりますか」

「今はならないと思います」

「往復する人間に、片道ぶんでいいって言うそうです。帰らないでいいなら、ここで寝ますけど」

　そのまま壁にもたれた。控室の鍵は懐中電灯と同じ紐に下がっていて、彼女が手を動かすと小さく鳴った。

「僕は二階の柱のところです。最初から最後まで」

　智也さんが先に言った。

「曲が始まってから、誰かいらっしゃいましたか」

「来ませんでした。最初の二つの音も、ちゃんと聞きましたよ。あそこで椅子を引くなって言ったの、僕ですから」

　それで、聞こえはしたのだろうなと思った。後ろの柱は客席の横一列をちょうど隠すほど太い。お嬢様が二階を降りてこられたのは、そのときだった。

「澄乃。あなた、さっきの歌をどこでお聞きに？」

「一階で、春江さんと。数え終えてから発見するまで一緒でした」

「開会のベルの前から、あなたが二度呼ぶまで、ずっと冴子さんの隣で照明の調節に付き合っておりましたわ。途中で暗すぎて、わたくしの指まで見えなくなりましたけれど」

「指だけ出しても、暗いんですから」

「それで最後はあなたの腕を叩きましたでしょう」

　冴子さんが、ちょうど左肘のあたりに右手をやった。お嬢様の指はあまり重くなかったはずだが、冴子さんは、ひどく痛いところを思い出したような顔をした。

「じゃあ話は済んだでしょう」

　智也さんが階段のほうを向いた。頭の上で、椅子を動かす音がした。

「二つ、とおっしゃいましたわね」

　お嬢様はその方の顔を見ず、言葉だけ拾うようにおっしゃった。

　　　　　＊

　春江さんを連れ、五人で二階へ行った。司会に針を貸してくれるようお嬢様が頼まれた。言い方はまるで、机の上の果物を一つ取ってくれという調子だった。

　赤い丸の盤で、木を打つ音が二つ。お嬢様は女の人が息を吸うところで司会に針を上げてもらった。

　次は、銀色の印。司会が針を下ろすと、ピアノがいきなり鳴った。音が伸びているあいだに同じ声が、同じ言葉で歌い出す。よく知った声なのに、赤いほうで入れるはずの一拍に体を置いていると、銀のほうでは自分だけ置いていかれた。

「本番は銀でしたわ。司会の方が、外の傷を越えたところに針を下ろしてくださいました」

「そうですね。替えてもらったのは開会のちょっと前です」

「二つ聞いたことは、疑いませんわ。わたくしも、さっき聞きましたし。ですが、春江さんが鍵を掛ける前にお聞きになったことを、掛けたあとの居場所の証拠にはできません」

　客席のいちばん後ろからなら、柱の影が見えた。誰も座っていない薄暗いところに、椅子が一つ来客の方を向いていた。

　私は、受付の卓から階段口が見えなかったことを申し上げた。ぐっと重い脚を動かすと、足を挟まないよう外ばかり見ていた。誰かが内側を通っても気づかない。

「その間、春江さんは？」

「私と二人でなければ、卓は運べません。降りてきた方々の応対にもいました。鍵を開けた後も私がその隣におりました」

「冴子さんも私の隣ですわ。ベルより前から、澄乃が呼ぶまで。窓は内から閉じ、扉を開けられる鍵は三つ。智也さん。柱にいらした証拠はない。でも、それだけでどこにいらしたかまでは分かりません」

　お嬢様は一歩退いた。

「ですから、何をしていたか、ここでご自分でお話しくださいな」

　智也さんは、上着の内側へ手を入れた。白い小封筒が出てきた。口はもう開いていて、青鉛筆の「万」の折れた一画が見えた。

「僕の通帳にも、今日払えるだけ残ってなかったんです。明日なら別の仕事の代金が入る。今日これで払って、明日戻せばって」

　智也さんは封筒を机に置いた。数えたのは春江さんだった。最初と同じように十の位を小さな声で足し、もう一度始めから数えた。

　　　　　＊

　智也さんのお父様は、誰にも聞こえないように言ったつもりらしかった。

「今ここで払ってしまえば、丸く済む」

　まだ寄付の札を見ていらした。

「それは、明日の床の金です」

　春江さんが、札を指で押さえた。

「今日の賃金は、ご自分の財布を開けてください。足りないときは、足りないとご本人に」

「じゃあ客には何と言う。もう戻ったんだろ」

　春江さんは、しばらく紙を探した。私が例の封筒を差し出すと、その裏に、ごく短く書いた。私の名前を書く欄はなかった。

　司会が、次の曲名を言いかけて止まった。春江さんが、マイクを借りたのである。会計が九万円を受け取ったこと。控室から持ち出されたこと。全額を確認して受け取り直したこと。途中、机の向こうから智也さんが立ち上がり、持ち出したのは自分だと言った。誰かが後ろの椅子を直す音がしたが、今度は何の歌にも重ならなかった。

　私は一階で、戻った札が入った封筒に糊をつけた。二階から、お嬢様が階段を下りてくる音がする。いつもは、私がそれを聞いて先に戸を開ける。

　その日は一度だけ、封がしっかりつくまでお待ちいただいた。
