# 改稿記録

1. 環の発言を「返してって書いた」に修正し、実際のメッセージが返却の依頼であり、無回答を展示の許可に換えたのは語り手だと揃えた。
2. 過去のネームでブレーキを握る手、道につく片足、待つ一コマを別々に示した。
3. 記事の呼び物を作者が取り消す場面にし、作業当日の写真締切と翌日の朝刊を整合。ネームを引いても成果を名指しできることを、合意を得た範囲の札で示す。元相棒の私的事情は載せない。
4. 画鋲の比喩を冒頭だけに戻し、終幕で二枚を続けて見られるよう椅子を畳む。客の目を誘導する仕掛けを外すという、最初の札に対する行為で閉じる。
5. 表紙の人物同定を補うため、鏡の場面に短い髪と耳に掛けた側の所作を入れた。環の紺と結び髪、作者の珊瑚色は初稿から変更なし。

独立担当が改稿箇所を再読してPASS。原因の修正は本文に適用し、閲覧画面側は変更しない。
