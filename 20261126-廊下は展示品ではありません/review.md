# 本文批評

草稿本文だけを別に読み、受付から奥へ向かう順に移動を再構成した。同一担当者の批評工程であり、外部の読者の評価ではない。

- 導入と反復 PASS。開ける相手を取り違える→左右を取り違える→扉の外の声の用事を取り違える。同じ台詞を増やすのではなく、障害が人、荷物、向きに変わる。
- 客の位置 FAIL。最初に三人を内側へ入れ残りは玄関へ下げたのに、実演時の扉の前には連れだって三人がいた。各組の再配置が本文にない。玄関に下がった四人のうち声係だけを呼び、残りがつられて動く様子を具体化する。
- 終盤の動線 FAIL。二人一組が続いて反対向きに出入りすると、衝突の解決が「自然と」に委ねられる。見学客は一組ずつ、玄関で次を止める、日常の往来を優先する順を明記する。
- 古い傷と車の理解 PASS、ただし傷の由来は断定できない。角度と写真の一致は案内人が関心を移すきっかけで十分。
- 身体動作および語の精度 要修正。腕を組んだだけで腕時計が耳元に来るとは読みづらい。「一脚ずつ脚」の重複と末尾の袋の再登場を整理する。
- 主人公の選択 PASS。見学を投げず、他人を廊下から締め出さず、実演を二人単位に変更する。無音の価値を否定して終わらない。
- 落ち PASS。「人が壁の一部になる」を会費の話へ戻す。須田さんが客の介助や承認だけを担うのではなく、囲碁会の用事を続ける。
