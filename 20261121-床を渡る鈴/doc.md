# 床を渡る鈴

　二点目を取られたとき、順子の爪が千帆の靴の縁に引っ掛かった。

　千帆は決めてあった位置まで戻ったつもりで、左の柱へ手を、内側へ足を伸ばした。だが着地は中央寄りだった。足の裏が真ん中にいた順子の手に乗り、二人が重なった分だけ左が空いた。鈴の音はそこを抜け、背中のほうでネットをこすった。

　得点を告げる笛が鳴るまで、誰も喋らなかった。笛が鳴ると、観客席から椅子のきしむ音まで戻ってきた。

「端を空けた」
　千帆が先に言った。
「足、どうした？」
「平気」
「私の指のこと」
　順子は指を一本ずつ床に当てているらしかった。爪が木の床を軽く叩く音がした。
「動く。次いこう」

　一対二。相手は二度とも、こちらの左へ投げてきた。目を覆う黒いアイシェードの下は、開始から変わらず暗い。それでも点差がつくと、左の柱だけが遠くへ動いたようだった。

　ゴールボールのコートは幅九メートルある。三人が横に倒れてふさぐ。柱から柱まで体を並べればいい、と初めて来た頃は思った。実際には隣の選手とほんの少し重ならないと、間を球が抜ける。重なりすぎれば、さっきのように別の場所が空く。

　左端の千帆と真ん中の順子は、手と足を近づける。千帆の手は柱へ、足は内へ。床に貼られたテープの下に紐が一本通っていて、その盛り上がりを指で探す。ちゃんと線に戻っていれば、順子の手が千帆の靴に触れるか触れないかの距離になる。

　試合前、千帆はその線をまたいで何度も投げた。二歩下がり、三歩使って加速する。腕を低く抜けば、球は最初の区画で床につき、あとはほとんど跳ねない。速さだけならチームで一番だった。

　去年まで投げていたのは真ん中の順子だった。膝を痛めてから投球は減ったが、誰に次を投げさせるか、球を渡すときに決める。千帆はそれが嫌で、左に来た球はなるべく自分で取った。取った球をすぐ渡せと言われることはない。

　主審から球が戻った。千帆は片手で抱き寄せた。バスケットボールほどあり、片手で持ち上げるにはずしりと重い。いっぱいに詰まっているわけではない。傾けると、中で小さな金属の塊が壁を打つ。

「千帆」
　反対の端から真理が呼んだ。
「投げたら、私の声じゃなくて線を探してね」
「いつも探してる」
「着く前に倒れてる」

　主審の声がした。千帆は球を床から取り、左の線を一歩で越した。体の正面を相手の右へ向けたつもりだった。腕を抜くと、鈴が遠のく。その直後から自分の靴音が続き、両方がどちらへ行くのか分からなくなる。一歩、二歩。指がまだ床の線に届かない。相手のところで球が止まった音がした。

　声がなかった。球を拾った側の足音が、一つだけ前に出た。

　まずい、と千帆は思った。線を探すために伸ばした手を引き、左へ飛び込んだ。

　鈴は来なかった。

　遠い右側で、真理が短く息を吐いた。胴に球が当たったらしい。遅れて、床を跳ねる音が二つ。千帆は尻をついたまま、片手を腹に当てた。打たれたのは自分ではないのに、そこだけ冷たかった。

「ブロックドアウト」
　主審が言った。真理に当たって球が横の線を越した。笛のあと、ベンチの監督がタイムアウトを求めた。

　ベンチのほうから監督が来た。靴底を引きずる歩き方で分かる。
「こっちから見ると、相手は回り込んで即返すのが上手。向こうが止めた時点で、千帆は何歩目？」
「右が、二歩」
「その足で左に戻れる？」
　千帆は答えなかった。二歩目で左へ切り返す練習はした。成功するのは、投げるところまでうまくいった日だけだった。

　順子の手が千帆の右膝に触れた。
「一回、投げる前に戻る場所を決めよう」
「ここから投げたら読まれる」
「そりゃ読むよ。私たちだって読む」
　千帆は球を渡せと言われると思っていた。順子はもう膝から手を離していた。
「戻れない球は、いま要らない。戻れる球を、左から一つ出して」

　真理がさっき腹を打ったところに水をこぼした。ボトルの蓋が閉まるまで、誰も時計の話をしなかった。放送席のすぐ下に点と残り時間の表示がある。選手には見えないので、タイムアウトの時だけ監督が数字を言う。

「あと一分二十秒」
　監督の声はよく通った。
　真理は蓋を監督に渡した。
「私、もうあんな音したくないから。左にちゃんといて」

　球が来た。相手の右端の選手は、こちらが加速すると早めに床に落ちる。先ほども鈴より先に体の着く音がした。千帆はそこから手の長さ一つぶん外、柱のすぐ内側へ球を置くつもりで左から構えた。再開の声を待ち、横へは移動せずに投げた。踏み込む足は一歩だけ。最後に手を離すとき、床に膝を落とさないようにするだけで精いっぱいだった。いつもならその投げ方は練習の最後、片づけ前にしかやらない。球は大声で抗議するみたいに、ころころ鳴って進んだ。

　遠くの床を何かが重く打った。狙った先より少し内側で、さっきと同じ体の落ちる音だった。すぐ返されると決めて、足を引き、指の腹で紐の入った線をつかんだ。

　そこでゲームが止まった。
　短い笛が二本。
　続いた言葉は、こちらの得点だった。

　観客が拍手して初めて、千帆は膝の力を抜いた。球がネットに触れる音を聞かなかった。向こうの体でどこかの音を遮られたのかもしれない。真理がコートの反対側で一つ笑った。

「入った？」
「いま二対二って言ったじゃん」
「どうやって？」
「見てない」

　千帆は少し笑った。順子は笑わなかった。自陣の真ん中へ戻りながら、足の裏を二度置き直した。

「千帆、私から離れないで」
「左にいろって言ったのは」
「左の線にいて、倒れる深さだけ私とそろえて。内側に寄れってことじゃない」
　千帆は指を離して半歩下がり、また同じ紐へ触れた。体を先に置くのでなく、線を指で決めて残りの体を置いた。左へ手を伸ばした。順子に近いのは右の足だった。

　こちらが得点したので、次は相手の球になる。静粛を求める声がして、見えない席の端から順に人の気配が止まった。

　向こうの靴が鳴った。球の鈴はすぐには聞こえなかった。ずっと使ってきた速い球なら、踏み込む音の直後に床を打つ。その間に、今度は空白があった。

　鈴が真ん中へ来ていた。勢いよく飛び込む球でない。ボール一個分、順子の外へ逃げていく。千帆のほうへ少しずつ曲がっているように聞こえた。

　起きれば、その球へ肩から行ける。失点のときとちょうど逆に、こっちから間を詰めればいい。

　千帆は起きかけた。膝を引くと靴のかかとが浮いた。そこに順子の手の甲が触れた。さっき踏んだ指が近くにあると分かった瞬間、自分から動かなければと考える声が一段低くなった。

　千帆はかかとを床へ下ろした。右足のつま先を伸ばし、向こうから来るものを待った。

　先につかまえたのは順子だった。かすれた息がして、球がつま先と順子の腕の間でつかえた。鈴は二つ、近い音を立てたきりだった。

「真理」
　順子は床から球を送った。千帆のほうではなかった。
　順子が最初に触ってから十秒以内に、返球をセンターラインの向こうへ出さなければならない。千帆は口を開けずに、滑っていく音を追った。真理が受け、片足で立ったときの、重さの乗った音を聞いた。速い球だった。千帆の球より二つ余計に床を打った。誰にも触れず、そのまま向こうのサイドラインを割った。

　残り時間は、まだあった。

　二人の間でもう一度速い球を止め、真理が返した。向こうが次の球を拾った直後に終了の合図が鳴った。

　予選の試合はそこで引き分けた。笛が鳴っても、千帆はすぐにはアイシェードを取らなかった。柔らかいゴムが耳の上を締めていて、そこに汗がたまっていた。端を片手で押さえると、汗が首の横まで流れた。

「勝ちたかった」
　先に言ったのは真理だった。
「私も」
　順子が答え、三人は起き上がった。ベンチへ戻る前に目隠しを外すと、表示板の二つの数字が、同じ大きさで光っていた。

　次のチームが入る前に、千帆は一歩だけ線の外に出た。自分が投げていつも着地する場所から、左の紐までを歩いてみた。誰も倒れていないコートは思っていたより狭く、指で線を探す時間だけが抜け落ちていた。

　千帆は元の場所へ戻った。
「順子、そこ、もう一回寝てくれる？」
「今？」
「次の人が来るまで。一球いらない」
　順子は空のコートとベンチを見比べ、床に片膝をついた。千帆はその隣で、まず自分の線を指で触った。

　まだ一度も踏んだことのないみたいに、紐が固かった。
