# 批評：着氷線の外

初稿の本文だけを別工程で読み、企画を成立の根拠に使わず再構成した。別の人間による査読ではない。

1. 弟子の志乃はペアを辞めた兄の肩を、単独練習でも仮想の目印にしている。
2. クラブの早朝練習枠を取るには、観覧者の兄から合図を受けず二分滑る。兄は席を移ることを申し出るが、志乃は断る。
3. 最初の跳躍で両足が降り、予定の足運びに入る地点を通り越す。
4. 志乃が右刃の弧を止めずに外側を回ると、次の跳躍への助走を長く取れる。二回目の着氷は右一足。曲を止めず滑り切る。
5. 結果は翌日まで出ない。志乃は兄が待つから演技を終えるのではなく、自分で線を見直す。

|観点|初稿判定・本文だけからの指摘|
|---|---|
|因果|要改稿。肩一人ぶんの空きと右膝が揺れる間に、一回目の軸を戻せなかった身体の感覚が欲しい。現状では両足着氷の原因を補読させる。|
|時空と視線|要改稿。「一度も顔を上げずに見たと思い込んでいた」は、客席の手と袋を見た場面と衝突する。席の見当を付けたのは演技前に限定する。|
|助走と選択|PASS。外へ流れた刃を減速させないことにより、振付一つを失う代わり、速度を保って次の跳躍に届く。戻る場合も失うのは振付なので、選択上の実利を一文足すとよい。|
|人物|要改稿。「膝のコンビニ袋」はすでに座席の下に移った。「弟子」はこの批評上の整理語で、本文にはクラブに通うことだけ残す。|
|選考の結果と結末|PASS。補欠や合格を後から足さない。兄と見ているものが違っても沈黙でなく短く話ができるが、土曜に滑るふりはしない。|
|類型と文体|PASS。音を使う点は11/21と隣接するが、競技中に配置をチームで直すのでなく、一人が助走を作り直す。視線位置を詰めれば読者も一つの弧として追える。|
