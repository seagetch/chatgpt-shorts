# 花嫁より高く

　姉の結婚式へ行く朝、私はパンに乗った。

　試したことはなかった。パン屋になって七年、焼かずに出かけるのも初めてだった。

「花嫁より目立とうなんて、考えないほうがいいよ」

　隣の粉屋のおばさんが言った。

　私は長い上着の裾を籠へ押し込み、聞こえなかったふりをした。

　　　　＊

　風麦の生地は、膨らむと浮く。

　こね鉢を台へ縛っておくのは、どこの店でも同じだ。うっかり放しても、焼き目をつければ落ちてくる。親方はよく、天井へ張りついた丸パンを長い焼きごてで突いていた。

　私が育てた早種は、それまで一晩かかった生地を、朝のうちに膨らませる。おかげで寝坊のできるパン屋になった、と粉屋には言われた。寝坊をするために、何度徹夜したと思っているのか。

　今日は、この種を姉に渡すつもりだった。

　姉は山の向こうで宿をやっている。朝食の仕込みが楽になる。きっと喜ぶ。それから少しだけ、私を見直すだろう。

　手紙には、仕事道具はいらない、客として来て、とあった。

　私は種壺を籠の底へ入れた。姉は何でも先に決める。私が言いたいことまで。

　朝一番の荷車で行けば、昼の式には間に合うはずだった。ところが、昨日の雨で谷の橋が落ちていた。遠回りの峠道を行くなら、着くのは明日になる。

　空はよく晴れていた。谷から山へ、雲が流れていた。

　私は店の天井を見た。

　昨夜、早種を多く入れすぎた六つの丸パンが、ひもを張って浮いていた。

　　　　＊

　粉屋に手伝ってもらい、丸パンを一つずつ布の網で包んだ。六本のひもを、配達用の大籠の縁へ結ぶ。石臼の上石を載せても、籠は床から指二本ぶん浮いた。

「どうやって降りるの」

　私たちは同時に、店の焼きごてを見た。

　旅用の小さな炭火鉢を借りた。蓋の穴から熱したこてを出せる。籠の底に鉄板を敷き、火鉢を針金で留め、赤く起こした炭を二つ入れる。パンはひもを手繰れば下へ引ける。焼き目を一つずつつけて、浮く数を減らせばいい。

　ひもと結び目は、何度も確かめた。

　姉なら、一度で済ませる。

　こては店の竈で十分に熱しておいた。街道は山を回るが、まっすぐ谷を越せば宿は近い。着くまでに冷めることはないと思った。

　私は上石を下ろし、代わりに籠へ入った。籠の縁に結んだ命綱を、地面の粉屋が両手で握っていた。それを少しずつ繰り出すと、店の窓が足の下へ来た。

　粉屋が予備の炭袋を差し上げた。籠の中へ載せると、足元が下がり、窓がまた目の高さへ戻った。私は袋を返した。

「その上着を脱いで、炭を持って行ったら」
「式だから」

　上着は、杏色の麻に白い花を刺したものだった。膝から下に、無駄なくらい長い布がついている。祝いの服だと店の人は言った。誰を祝う服かは聞かなかった。

「着いたら知らせてよ」

　粉屋が綱を離した。

　私は、知らせる鳩を借り忘れたことに気づいた。

　もう、煙突より高かった。私は綱を手繰り上げ、籠の内側へ丸く収めた。

　　　　＊

　はじめのうちは、実に具合がよかった。

　町が小さくなり、街道が細くなった。いつも半日かかる畑の端を、パンはじきに越えた。焼く前なので匂いも控えめで、鳥はついてこなかった。

　私は火鉢の蓋を押さえ、姉の家を探した。

　赤い屋根が見えるはずだった。

　その代わり、山の頂上が見えた。

　私は、籠の縁を握り直した。

　出発したとき、パンは大きな林檎くらいだった。それが今は、六つとも冬瓜ほどになっている。早種は、よく働いていた。

「もう十分」

　言っても止まらない。これで言うことを聞くなら、鉢を台に縛る必要もない。

　ひもを一本、手繰った。生地は上へ行きたがり、私の腕は下へ行きたがった。二の腕でひもを挟み、熱したこてを当てる。

　じゅ、と鳴った。

　小さな茶色の丸ができると、そのパンだけが急に重くなった。私は網ごと抱き留めた。

　籠が傾いた。

「一個では、まだ」

　焼いたパンを足元へ置いた。上昇は鈍ったが、止まらない。

　二個目を手繰り寄せたところで、こてが生地に貼りついた。焦げ目はつかなかった。

　火鉢を覗く。

　炭は、灰の下でほとんど消えていた。

　谷を越したらすぐ使うつもりの火だった。こんなに高くまで、こんなに長く持たせるつもりはなかった。蓋を開けて息を吹くと、灰が顔へ戻ってきた。

　眼下に赤い屋根が現れた。

　姉の宿だった。

　庭に、白い布が渡してある。椅子も見える。姉が一脚ずつ向きを直したであろう椅子が、綺麗に並んでいた。

　椅子の列から白い人影が離れた。もう一人が続き、二人とも庭の門へ走っていく。

　私は手を振った。

　その全部が、ゆっくり後ろへ流れていく。

　　　　＊

　籠には、種壺と火鉢と、六つのパンしかなかった。

　それから、私が着ているもの。

　上着の袖をつまんだ。白い花が、指の間で折れた。

　姉に会ったら、まず何と言うつもりだっただろう。

　似合うでしょ、だった気がする。

　私は裁ち鋏を持っていなかった。パン切りの小刀だけは、癖で腰へ差していた。裾に切れ目を入れ、縫い目を両手で引いた。

　びり、と、よく通る音がした。

　細く裂いた麻を、赤い炭の残るところへ押し込んだ。息を吹く。今度は顔を横へよけた。

　布は端から黒く縮み、火になった。

　こてを入れ、また布を裂いた。長い裾がなくなると、足首が寒かった。白い花が一つ燃え、次の花を裂いた。

　姉は刺繍も上手だった。私が初めて縫った花を、蜘蛛みたいだと言った。

　腹が立って、私は蜘蛛をもう一匹縫った。

　姉はそれを、自分の鞄へつけて持ち歩いた。

　何年も前のことだった。

　こてが熱くなった。二個目に当てると、パンの皮が鳴った。

　籠は、ようやく下がり始めた。

　下には宿ではなく、林があった。

「そっちじゃない」

　それまで一度も、パンに行き先を伝えていなかった。

　私は籠の縁へ立ちかけ、すぐに座った。木の枝が届くほど近くなったところで、下から声がした。

「綱を！」

　姉だった。

　庭から走って来たらしい。白い花嫁衣装の裾を片手でたくし上げ、もう片方の手を伸ばしていた。隣には、会ったことのない男の人がいた。二人とも、式の靴では走りにくそうだった。

　私は丸めておいた命綱の束をほどき、輪にした端を落とした。男の人が拾い、姉が近くの木へ一周させた。

　籠がぐっと止まった。

　私は三個目を焼いた。

　姉たちが綱を引き、籠は枝を擦りながら、草の上へ下りた。

　　　　＊

　姉は、私の顔を見た。

　それから上着の切れた裾を見た。

「蜘蛛、減ったね」

「これは花」

「知ってる」

　姉は笑った。私も笑おうとしたが、足が震えてうまく立てなかった。

　男の人が籠を押さえてくれた。姉は私の腕を肩へ回し、引っ張り上げた。

「走らせないでよ、今日くらい」

「橋が」

「知ってる。迎えを峠へ出そうとしてた」

「明日になるもの」

「式は今日だけど、私は明日もいるよ」

　姉の袖に、灰がついていた。払おうとすると、いい、と言われた。

　私は籠から種壺を出した。

「これ。朝の仕込みが早くなる」

　姉は受け取り、蓋の隙間から覗いた。

「このパンの？」

　私はうなずいた。

　姉は壺を両手で持ち直した。

「台へ、きつく縛るね」

　　　　＊

　式は、少し遅れて始まった。

　私は借りた上着を着て、庭の端へ座った。姉の花嫁衣装は、草の汁のついたところを後ろへ回してあった。隣に立つ人の靴も、同じ色に汚れていた。

　六つのパンは、宿の竈で最後まで焼いてもらった。中はまだ生だったからだ。私は席から立ち、焼き加減を見に行きたくなるたび、膝の上で手を組んだ。

　誓いの言葉が終わり、姉がこちらを見た。

　私は両手を鳴らした。

　食事が始まると、私の前にもパンが一つ置かれた。焦げた丸い印がついている。ずいぶん大きい。

　姉が椅子を持って隣へ来た。

「半分ちょうだい」

　小刀を出しかけると、姉は先に両手で割った。

　湯気が立った。大きいほうを私の皿へ載せ、自分は小さいほうへ歯を立てた。

　私は、姉の皿からそのパンを取り返した。

「今日は、そっちが大きいほう」

　姉は口の端に粉をつけたまま、私の皿を引き寄せた。
